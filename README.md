# 🎮 Tic-Tac-Toe Game - Modern Edition

Welcome to the ultimate Tic-Tac-Toe gaming experience! This is a beautifully designed two-player game with a sleek modern interface where you can enter your names and take turns to play Tic-Tac-Toe. The game features stunning animations and a contemporary dark theme.

## ✨ Features

- **Two-player game**: Enjoy a classic game of Tic-Tac-Toe with a friend. Compete to see who can outmaneuver the other and claim victory.
- **Customizable player names**: Make the game your own by entering custom names for Player X and Player O. Add a personal touch to your matches.
- **Modern Design**: Experience a sleek dark theme with beautiful gradient accents, glassmorphism effects, and smooth animations.
- **Interactive Gameplay**: The game offers an interactive and user-friendly interface. Simply click on the cells to make your moves. The grid elegantly displays the current player's turn with real-time updates.
- **Smooth Animations**: Enjoy fluid transitions and animations:
  - Slide-in header animations
  - Pop-in effects when placing symbols
  - Smooth hover effects with scale and glow
  - Ripple effect on button clicks
  - Fade-in element animations
- **Winning Announcements**: When a player wins the game, our Tic-Tac-Toe application will proudly display the victorious player's name with a celebratory message and emoji.
- **Responsive Design**: Whether you're playing on a desktop computer, tablet, or mobile device, our game's responsive design ensures that you can enjoy Tic-Tac-Toe anywhere, anytime.
- **Easy Reset**: Want to start a new game? No problem! A convenient "New Game" button allows you to quickly clear the board and begin a fresh match.

## 🎨 Design Highlights

- **Color Palette**: Modern gradient with blues (#667eea), purples (#764ba2), and pinks (#f093fb)
- **Typography**: Premium fonts - Poppins for headings, Inter for content
- **Effects**:
  - Glassmorphism with backdrop blur
  - Gradient text for titles
  - Dynamic shadows and glows
  - Smooth transitions on all interactive elements

## 💻 Technologies Used

- **HTML5**: Semantic structure with modern markup
- **CSS3**:
  - CSS Grid for game board
  - CSS Gradients and animations
  - Glassmorphism effects
  - CSS custom properties (variables)
  - Responsive design with clamp()
- **JavaScript**:
  - Factory Functions
  - Module Pattern (IIFE)
  - Event-driven architecture
  - Smooth DOM manipulation
